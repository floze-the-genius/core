# ВА-БАНК / ALL IN

Browser casino clicker (RU / EN). Plain HTML, CSS and JavaScript with no libraries, no build step and no external requests. All sounds and music are synthesized with Web Audio.

Open `index.html` directly or upload the `game/` folder to any static host.

- Six floors of the casino tower: Basement, Bar, Hall, VIP, Penthouse, Vault.
- Each floor unlocks a game: coin flip, slots, Plinko, wheel of fortune, rocket (crash).
- Opening the three vault locks ends the game (about 30 minutes for a typical player).
- Progress is saved in `localStorage`; offline income is paid on return.
